Help & Troubleshooting

This guide covers common problems when opening older MSN Messenger XML archive files in Messenger Archive Library.

Opening an archive

  1. Locate the XML archive on your Mac in Finder.
  2. Open it using the app's file-opening control.
  3. If macOS asks for file access, choose the archive you intend to open.
  4. Keep an unchanged backup of important archives before trying alternate tools or conversions.

The file will not open

  • Check that the file is a genuine XML archive and has not been renamed from an unrelated format.
  • Try opening a copy of the file, not your only original.
  • If the file is incomplete, empty, or malformed, the app may not be able to parse it.
  • Very large archives may take longer to load.

Messages or sender names look wrong

Archive files can differ by Messenger version, language, and export method. Confirm that the XML file contains message elements and sender information. If the issue persists, report a short description and the app version. Never attach private conversations to a public issue.

Search

Check the search term for spelling and try a shorter distinctive word. Search results can only include text present in the archive and supported by the app.

Printing or saving as PDF

  • Check that the intended conversation is selected before printing.
  • In the macOS print dialog, review the preview and page settings.
  • To create a PDF, use the PDF menu in the macOS print dialog if available.
  • For a blank or incomplete result, try a smaller conversation and check whether the same problem occurs.

Contact support

Use the GitHub issue tracker. Include your macOS version, app version, the steps that caused the problem, and any error text. Please do not post passwords, full chat logs, personal details, or original archive files publicly.
