# Messenger Archive Library Support

Support pages for Messenger Archive Library, an independent macOS archive viewer.

## Publish with GitHub Pages

1. Open the repository's **Settings** tab.
2. In the sidebar, select **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait for GitHub Pages to finish publishing. The site should appear at:

   https://andrewc70-lang.github.io/messenger-archive-library-support/

The privacy policy will then be at:

https://andrewc70-lang.github.io/messenger-archive-library-support/privacy.html

## Important before App Store submission

- Review `privacy.html` against the final app binary and all included SDKs.
- Review `APP-STORE-CHECKLIST.md`; the checklist is not proof of App Store readiness.
- Confirm every feature mentioned in the store listing is present and tested.
- Do not include private chat archives or personal conversation contents in public support issues.
